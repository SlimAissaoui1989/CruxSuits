# Security policy

## Supported versions

Security fixes are currently handled on the active `microservices` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub and include steps to reproduce, affected service/version, and potential impact.

Do not include real credentials, private keys, personal data, or production file contents in a report.
