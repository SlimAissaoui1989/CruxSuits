# Security policy

## Supported versions

Security fixes are handled on the default `main` branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Use [GitHub's private vulnerability reporting](https://github.com/SlimAissaoui1989/CruxSuits/security/advisories/new) if it is enabled. Otherwise, use the private contact information on the repository owner's GitHub profile, if available.

Include the affected service and version or commit, steps to reproduce, and the potential impact.

Do not include real credentials, private keys, personal data, or production file contents in a report.
